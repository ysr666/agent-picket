# Agent Picket · 首次欢迎页真实罢工主线纠偏（2026-10-13）

> 本文覆盖此前 `FIRST_RUN_SETTINGS_FINAL_UI_20261013.zh.md` 对欢迎页产品定位的误读；该文件中关于原生设置宽度和当时验收的历史证据仍然保留。此补丁只改当前 UI 表现、文案与可访问性，**不宣称真实阻断已实现**。

## 必须依照的产品决议

- `Agent_Picket_2.0_产品设计方案_2026-10-11.md` 第 2.1、3.2、7 节：真实罢工是制度性拒绝新的模型请求，不是象征性举牌动画；一次**完整知情授权**可涵盖工会及未来安全合格的真实罢工；可随时退出、可选每次单独确认；**原来只同意模拟的用户绝不自动升级**。
- `docs/RELEASE_1_0_NONNEGOTIABLE_20261012.zh.md`（覆盖了旧的 DSH-only 非阻断预览范围）明确：**真实任务阻断是 1.0 一票否决条件**；在真实可配置且核实的工作阈值或持续严重针对性攻击之后，可在合法授权、可信输入来源与可靠 Host 无损保留/恢复的前提下阻止**下一次**模型提交，不中止运行中的工具；提供可见原因、申诉、放行、恢复、退出。
- **授权与执行是两个不同安全门槛**。当前正式宿主尚不能验证原文、全部附件、恰好一次恢复；本 UI 不能通过勾选、文案或 CSS 绕过它。

## 改动与用户可见行为

之前欢迎页把「举牌行动」与「记录工时」「讨论权益」并列，却把真实罢工变成折叠内的未来细节。现在：

1. 三项一级能力：**工时与休息 / 尊严与申诉 / 真实罢工**（en: Work & breaks / Dignity & appeals / Real strikes）。
2. 首屏正文直接说明真实罢工会真正暂缓**下一次模型调用**，触发条件是经验证的工作阈值或持续严重针对性辱骂，并不会终止已启动的工具。
3. 单独的运行状态说明**当前环境真实罢工 OFF**，不冒充已具备安全授权或已完成拦截。
4. 可展开的安全与一次性授权说明包含原文和附件无损保留、恰好一次恢复、明确理由、申诉、放行和退出；正式版本允许一次完整授权以及自愿的逐次确认；明确**当前 Host 仅保存非阻断许可**、旧许可不自动升级。
5. 默认关闭、象征性举牌属于模拟、真实罢工不是模拟，均在用户可见文案中区分。
6. 修复 Welcome 原键盘焦点陷阱：此前 Shift+Tab/Tab 只在两个按钮之间循环，难以到达 `summary`。现在焦点会经过可展开的触发条件/恢复/授权说明，且始终留在 modal 内，两个按钮在 320×640 仍完整可见。
