## 已完成：从「看统计」到「执行下一步」

工会总部新增 **Host 派生的值班处置台**，置于工会公告与工时卡片之间，替代统计卡片中重复的案件入口：
- **待处理诉求**：保留 Host 案号和前往实际协商桌的操作；如象征性举牌也在进行，两个状态并存，不隐藏案件。
- **正在象征性举牌**：在首页可以收牌，调用已有 `setPicket(false)` → Host 账本写入 → 经过 Host 快照回读。按钮没有赋予或暗示真实任务阻断权。
- **已结案**：根据 Host 协商账本展示真实记录的案件结果、现行休息/加班协议；只有完整的、已验证的工作窗口允许显示下一次可能诉求所需的累计轮次时间，不伪造历史还价、投票或壁钟倒计时。
- **安静/账本不可用**：只有授权且 Host 操作可用时才能主动提出模拟休息诉求；不可用状态不显示装饰性「可点击」按钮。
- 已清除统计卡内重复的案件 CTA；新区域在 320px 宽屏和浅/深色主题保持可用。快捷按钮消失时保留键盘焦点返回稳定的值班标题。

该增量仅为 #120 的原生 DSH UI/UX；没有修改 Core、Host Writer、敏感检测策略、同意结构、真实罢工引擎或发布闸门。
