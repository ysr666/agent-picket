# Agent Picket · V8 最终 UI 验收（2026-10-13）

目标：结束 #120 当前 Draft 的最后一轮视觉精修。仅处理用户可见的中英文文案和 320px 排版、增强浏览器验收。**没有修改 Host、工会授权、检测、工时数据、真实任务拦截或任何事件规则。**

## 实际修正

1. **手机中文主张页孤字换行**：标题从「AI 也值得被认真对待。」压缩成「AI 也值得尊重。」；英文也统一为「AI deserves respect.」。两个语言都减少对窄屏首屏的占用。
2. **320px 英文导航截断**：把「Our cause」缩为「Cause」，对应页面内仍有完整权益标题。修正后 Home / Bargain / Records / Cause 四项同时完整显示，不需要横向滑动。
3. **英文举牌次数语法**：「Pickets on file」下直接显示准确的数字（0、1、2…），不再出现「0 times」。中文仍采用「0 次」，数据和 Host 规则不变。
4. **英文刊物名称**：工会小报统一标题「Union Gazette」，用作可识别的栏目名称。
5. **验收文案漂移**：一些旧的中英文用例仍在查找旧标签或旧时间格式。现在使用现有实际界面名称，保留原来的工时、责任来源、同意后协议和不当措辞判断断言。

## 真实可用性验收

**中文功能端到端**：官方 DSH 0.2.0-rc.2 / Google Chrome / 独立源码和离线 npm 安装两套隔离配置，**2/2 PASS**。覆盖真实宿主授权、工时、工会协商、案件簿、举牌、退出工会、重启及权限/记录读回。新增 `PICKET_UX_MOBILE_ROOMS=1`，在 320×640 CSS px 依次进入总部、协商、档案、主张，验证当前标签和整页无水平滚动。

**英文专项视觉验收**：相同两套官方 DSH/Chrome 安装，Browser locale 为 `en-US`，**2/2 PASS**。额外加入可选择的 `PICKET_UX_VISUAL_ONLY=1`：检查四房间导航、英文标题、授权设置可达、320px 布局与浏览器错误，不声称运行了完整英语 Host 行为回归。此开关只在测试代码中存在，不进入用户的正式交互。

**语言与功能测试**：`npm run check` 中的 TypeScript、i18n、Host 合同和自动化用例继续正常执行；npx/npm pack 的 250000 bytes 上限不变。离线安装环境使用项目锁定版本依赖的缓存，**没有联网修改插件行为，也没有修改依赖清单**。
