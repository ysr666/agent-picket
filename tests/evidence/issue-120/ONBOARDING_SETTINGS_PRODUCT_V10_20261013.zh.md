# Agent Picket · 第一次启动与设置页产品化复核（2026-10-13）

## 依据与目标

本轮直接落实原始《Agent Picket 2.0 产品设计方案》（工会组织、AI 权益、诉求—协商—罢工—恢复主线），并遵守 `docs/RELEASE_1_0_NONNEGOTIABLE_20261012.zh.md` 的六项首发条件及真实授权／无损恢复的 NO-GO 边界。更正 #122 前一轮“视觉测试全部通过即产品化完成”的不准确结论。

### 首次开屏

- 不再是三个泛化的功能标签。**「工会流程 · 示意」**以四步小型排版展示「核实工时 → 提出诉求 → 真实罢工 → 放行复工」，强调这是一条**制度流程示意，并非发生中的 Host 行动**。
- 在首屏醒目显示真实罢工后果：已验证超时或持续严重针对性攻击，可能真正暂停**下一次**模型提交，不会中止正在执行的工具。
- **运行状态与授权范围分开、同时可见**：「真实罢工目前关闭／安全恢复尚未验收」+「本次加入只授权本地工作记录、协商和象征性举牌，不授权真实阻断」。不会用一次旧的模拟授权自动升级为真实拦截。
- 详细的原文、附件、来源、幂等恢复、申诉/放行、一次知情授权与可选每次确认，继续在键盘可操作的安全说明内提供。
- 两个选择「加入 AI 工会 / 暂不开启」在 320×640 的中文、英文、明暗主题下均与**实际的非阻断许可解释**一起完整可见；对话框异常短高允许滚动，没有隐式同意。
- 保留醒目的旗标、工会式行动编号与克制的品牌文字；没有编造 AI 意志、成员投票、假罢工记录或真实权限。

### DSH 宿主原生设置

- 首要卡片只有经 Host 核实的加入/退出与当前参与状态。
- 新增**常驻「真实任务阻断」状态卡**，说明“暂不开放 / 不会自动阻断”、真正的任务后果和「说明原因 → 暂停新任务 → 放行／恢复」，避免把最重要的产品能力完全藏入折叠区。
- 「安全条件与授权选项」可展开：完整无损恢复的门槛、真实阻断与逐次确认的**禁用控件**和本次许可不包含真实阻断；没有伪造可点击的授权选项。
- 更改的全部是产品展示代码和中英文可见文案；未改 Host consent schema、Settings 写入、工作阈值、辱骂判定或真正请求拒绝，**不代表已经实现真实罢工**。
- DSH 0.2.0-rc.2 原生设置仍有上游 **#124 / 320px** 容器问题：宿主侧边栏仅剩 36px 注入空间，不能称原生设置在 320px 通过。桌面/640px 可用，本 PR 不越权替宿主更改全局 CSS。

## 实机与自动化证据

- `npm run check`：424 项测试，**380 PASS / 0 FAIL / 44 conditional SKIP**；`npm pack --json --dry-run --ignore-scripts`：**249658 bytes**，低于 250000-byte 既有严格门槛。CSS 源内样式精简是为遵守既有 npm 体积合同，没有放宽测试。
- 官方 **DSH 0.2.0-rc.2 Chrome** 隔离 Profile 与实际非空 Host Session：中文首次启动（源码 + 完全离线独立安装）**2/2 PASS**；英文首次启动（源码 + 独立安装）**2/2 PASS**。验收包括真实授权读回、暗色/320px 页面渲染和辅助技术 DOM/键盘合同。
- 浏览器新增硬断言：真实罢工状态与「本次授权范围」都必须完整出现在 320×640 的固定操作按钮**上方**；两按钮完整可点击，不能只靠可滚动页面宣称“告知”。旧的仅模拟许可写入逻辑无变化。
- 原生设置与工会 Host 历史/权限回归：源码版及离线安装 **2/2 PASS**。桌面与 640px 暗色查看真实 UI，未获得真实阻断许可，不会开启危险拒绝。
- GitHub 多平台 CI 仍需对同步后的最新提交另行确认。Chrome AX 自动测试**不是**真人 VoiceOver/NVDA/触控验收。

## 判断与发布门槛

这是更接近真实工会产品的一版 **UI 源码＋自测实机候选**，可以交给负责人进行主观审美和真人操作验收。**不把设计意图伪装为已经上线的真实阻断**。正式 1.0 仍需完整版本化一体授权、可信 Host 接入、拦截/原文及附件无损恢复，以及 DSH Web/Desktop、Codex、Claude Code × 三 OS 的真实验收；这些未通过前不能合并/发布 1.0。保留 Draft PR #122。
