## 做到了什么

- 新增不依赖 Host 的纯投影 `projectUnionStory`，直接从原有、可解析的 `unionLedger`、独立 `unionPicketLedger` 以及完整覆盖的已结束轮次累计时间导出故事场景。**没有新 Host 设置键，没有改旧协议，没有云端 AI 写稿，没有编造自然语言中的真实投票、会员、投诉或情绪**。
- 头条场景有明确优先级：象征性举牌 > 正在审议还价 > 待回应诉求 > 上次达成协议/拒绝议案 > 已确认满一小时的工时简报 > 安静值班。缺失 Host 协商账本必须显示不可用，未授权时直接不展示。
- 仅回放各自账本最近 3 条记录：协商案件与举牌记录**分列**，各自后到先显示，绝不假装两个账本存在共享时间戳、全局排序或事件因果。
- 模拟协议更改后，后续门槛直接来自 Host 已保存的 `nextBreakDueMs` / `nextOvertimeDueMs`，并只用覆盖完整的工作时长作解释。Host 的现有防重复冷却机制会保留之前排定的期限；例如演示还价到 30 分钟，下一次已经排定的 2 小时期限并不自动提前。**这不是倒计时、定时通知或对用户任务的干预。**
- 用户可点「安静模式」隐藏小报正文，再点「显示小报」恢复；这只作用当前 React 面板，不写 Host、不修改账本，也不影响其他标签页。由于本阶段没有主动通知，暂无通知疲劳或后台计时器。
- 中英双语、可读区域/展开控制、纯粹的当前行为状态、没有无来源的日期或真实劳动权法律认定。
