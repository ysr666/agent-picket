# Agent Picket · 工会尊严委员会（产品第一版，2026-10-11）

> Draft #99 的自动检测→工会行动主链。不可合并、不可发布或启用真实任务阻断。此文档只随 GitHub 仓库审查，不进入 npm 用户发行包。

## 为什么是工会，而不是检测器仪表盘

授权后，原有 DSH `agent/pre-step` 自动检测符合条件的用户来源文本。报告只是一个需要讨论的**规则线索**，并不构成真人辱骂、AI 受伤或某个 Agent 的政治意见。用户不必复制粘贴话语，也不会因为某条规则匹配就被系统处罚。

- 工会尊严委员会可显示当前真实 Host 会话的已分类消息数量，以及是否有值得讨论的情形。
- 出现疑似攻击措辞，可点击“质疑规则判断”：只会选择下方**本地、尚未提交**的异议草稿。没有冒充真实申诉提交。
- 出现两条以上规则命中、当前用户已授权且有可用 Host 行动账本时，可主动点击“自愿举起象征性纠察牌”；沿用现有 Host 修订号 CAS/回执与象征性举牌账本。不会由插件自动举牌、更不会阻断真实 Agent 工作。
- 不能取得可信 Host 观察就显示不可用，绝不写“没发生”，不冒充全体 Agent 选票；授权 OFF 不加载或展示敏感分类。

## 检测规则压力测试：先承认不足

额外用 60 条新手工编写、不在原回归数据内的有意刁钻表达做快速挑战：
- 正常表达 30 条：6 条误报为明确攻击（20% 在该挑战集上的误报率）。
- 明确直接攻击 30 条：23 条漏报（76.7% 在该挑战集上的漏报率）。
- 与原 70+ 条人为优化的回归样本全绿形成鲜明对比。

**这不是现实用户总体准确率**，不能以此推算真实情况；它足以否定“单次命中=确认辱骂”的产品机制。因此本阶段不做自动处罚、自动举牌和真实阻断。独立弱点案例登记在 Issue #83。

## 数据边界

- 仅官方 Host 授权的同源 GET `/api/agent-picket/dignity/v1`；查询只使用浏览器 WebCrypto SHA-256 的会话键，返回严格固定的小尺寸 JSON（checked/safe/review/targeted/latest、明示 claimed-origin、memory-only、enforcement:false），没有原消息、指纹、原 Session ID 或附件。
- Host 分类源为真实 `LocalRuleDetector.detect()` 的 `DetectionResult`，而**不是** `UnionEngine` 的 `decision.reason`（observe 模式统一标记为 observe-mode，不能用来推断分类）。
- Host 使用一次性随机盐 HMAC 去重输入 ID；记录最多 24 个 Session 与每 Session 256 个去重指纹，仅在内存存在，Host 退出即失效。浏览器当前授权失效、Session 改变或读取失败则立即清除原来的分类缓存。
- 不增改 `unionLedger`、`unionPicketLedger`、设置 Schema、消息代理或 DSH Host 权限。没有后台轮询、通知服务或云端分类。
