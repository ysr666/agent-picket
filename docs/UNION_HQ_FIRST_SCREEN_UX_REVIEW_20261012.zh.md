# Agent Picket · 工会总部首屏交互改进（2026-10-12）

范围：全新 DSH 0.2.0-rc.2 Web 插件，真实 Chrome 已授权工会总部。本轮是实际已修改和复测，不能替代真人可用性、VoiceOver/NVDA 或独立安全验收。旧数据格式不属于当前首发目标。

## 已观察的问题与改进

1. **首屏缺少下一步指引**：此前操作区域按标题、举牌仪式、历史档案／委员会、小报、工时快报、公众倡议、章程、协商桌分布。实际提诉后需要跨越大量内容才能找到真正处理诉求的入口。现在工会总部按“**真实 Host 工时与案件摘要 → 行动 → 协商桌 → 尊严委员会 → 小报 → 细节档案**”组织。用户更快看到当前发生什么、能做什么、下一步在哪里。
2. **象征性海报挡住行动按钮**：首次真实 Chrome 截图显示仪式海报先出现，1280×850 可见范围内关键操作按钮被推到下面。现在把“发起休息／加班诉求、举牌／收牌”及真实非阻断状态提示放在海报前面。更新后的实机截图确认 1280×850 初始屏幕能看到三个行动按钮。仪式与荒诞工会风格保留，不抢操作焦点。
3. **倡议不能方便地复制**：议题板此前只有只读本地文案和 GitHub 链接。现在增加中英文“复制倡议草稿”按钮：必须用户主动点击，只复制当前选中的公开模板，不读取 Host 记录、不自动发布；成功／失败提供 aria-live 可见反馈，剪贴板不可用时引导手动选中文本。切换议题重置反馈；不伪造投票或成员数量。

## 同日追加：协商结案连续性与倡议复制竞态

- **结果不再藏在统计后面**：已归档的模拟协商决议此前排在工时、不满指数之后，协商提交成功后焦点却回到协商室，用户难以在当前位置看到回执。本轮直接将原有、基于 Host 真实保存结果的回执移回协商室，保留案号、接受/拒绝状态及现行工作条款；在前面工会行动区标示最近一次协商的案号。没有添加第二张重复回执卡，也不暗示模拟协议会阻断真实任务。
- **结果边界更明确**：文案区分“该案已结”与“目前有效的协议条件”，并注明条件未必因该案改变。不虚构 AI 投票、签署人或集体行动。
- **切换倡议后的旧复制回调不再误报**：剪贴板异步写入请求按本地交互序号作废；换议题或者再次点击后，之前的成功或失败结果都不能覆盖当前议题的状态。尊严委员会跳转至申诉议题也重置之前的复制状态。没有额外 Host 写入或上传。
- **复测（2026-10-12）**：全量 385 项（341 通过、0 失败、44 条条件跳过）；真实 DSH 0.2.0-rc.2 Chrome 源码和 npm 离线安装两组均通过（2/2），覆盖协商回执、重新加载、真实剪贴板写入、旧 Promise 异步完成后的换题反馈；最终 npm pack dry-run 约 234 KB、101 文件。实机截图：`/tmp/agent-picket-ux-receipt-20261012/source-firstfold.png`、`installed-firstfold.png`。代码自动验收不是 VoiceOver/NVDA 真人签收。
