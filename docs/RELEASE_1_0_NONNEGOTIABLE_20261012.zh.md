# Agent Picket 1.0 正式首发：负责人最新不可缩减范围（2026-10-12）

**本文件覆盖此前任何“先发不阻断预览版”、“首发仅 DSH”、“Codex / Claude Code 留待下一版”的产品决定。** 保留历史验收材料，不抹去真实技术阻碍。用户未批准合并、发布 Tag 或 npm。

## 六项一票否决条件

1. **真实任务阻断，而不是象征性举牌**：在支持的真实 Host 客户端内，达到可配置并经过真实事件验证的时长阈值或持续严重针对性攻击时，必须真正阻止下一次模型提交；只有合法授权后才可触发。不得中止已启动的工具、破坏文件或把合法技术批评当成人身攻击。
2. **零丢失拒绝与恢复**：提交原文、所有附件、顺序和来源信息在阻断后由 Host 本身可靠保留；用户当场看到警告、原因、可操作的异议／绕过／恢复。一次提交不可凭空丢失或执行两次；需测试关闭/撤销、重启、并发、多个标签页。
3. **好看、有用且统一的 UI**：真正的工会总部，明确展示工时、案件、诉求、协商、象征性和真实行动状态，视觉系统跨屏幕尺寸、亮/暗主题和无障碍可用；不能仅有工时表或仪式海报。
4. **独立设置页面**：宿主原生授权（单次完整知情加入工会可含未来真实阻断）；默认关闭，支持随时退出/恢复，也可选“每次阻断单独确认”，绝不能将旧版仅模拟授权自动升级。
5. **首次启动弹窗 + 阻断前的警告**：首次说明 AI 工会宗旨、何时可能阻断、真实后果、用户控制权；实际阻断发生时必须再次提供具体原因和可恢复操作。页面上的预告不能代替真实的阻断反馈。
6. **三 Agent 平台 × 三操作系统**：Agent 平台固定为 **DSH、Claude Code、OpenAI Codex**；操作系统固定为 **Windows、macOS、Linux**。DSH 需分别支持 **Web 和 Desktop 两个客户端**；不要求独立 ACP 或泛化 CLI 作为额外首发端。Claude Code、Codex 按各自官方客户端实际方式接入。不能把 Node stdin Hook 单测当成完整宿主适配。

## 工程发布闸门

`npm run release:gate` 将核对 `release/first-release-evidence.json` 是否具备各端／各平台真实强制拦截、原文附件恢复、来源证明、交互体验以及真人验收的证据。默认 `NO-GO`。该工具不是安全性的证明，只是避免开发者看见 CI 全绿便错发版本的一层额外保护；所有证据仍需独立审查。

目前 DSH 0.2.0-rc.2 的 `pre-step.reject` 不满足安全保留接口；Codex 和 Claude Code 的实验性 stdin Hook 仅非阻断警告，不具备被实测认证的完整恢复。不可为了满足时间表而伪造凭据、软宣称“已支持”或悄悄启用危险拒绝。**第一版没有可靠完成全部条件前，不给承诺上线日期。**

可以在同一个 Draft PR #110 上继续开发核心策略、UI、授权与真实 Host adapter；经负责人明确同意后才合并及发布。
