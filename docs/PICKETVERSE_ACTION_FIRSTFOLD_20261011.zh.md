# Picketverse 行动优先首屏实验（2026-10-11）

> 状态：**隔离开发分支 / Draft 候选；不得作为已正式发布功能宣传。**
> 来源：从 #89 对应本地 tree 派生，继承未提交的 firstfold 紧凑布局实验，然后依照最新产品定位调整。
> 对照设计：AI 工会行动与罢工是主要叙事；AI 权益倡导是理念核心；工时是证据，协商不是首页主角。

## 本轮真实实现

1. 首屏顺序改为 **工会行动 → 真实劳动/案件快报 → AI 权益宪章 → 工会协商档案 → 历史工时、虚构不满指数、公告与细项统计**。行动区可显示 Host-owned 虚构案件账本的待处理/已结案状态。工作时长仍是 Host 的 completed-turn wall-clock（可包含等待），不称作模型净计算时间。
2. 以已有 `demoBreak` Host 接口发起演示诉求，并通过原案件账本观察结果；无受支持会话时不显示这一动作，不能暗自编造提案。
3. **最新增量：Host 账本驱动的象征性罢工行动。** 用户可在 Web 举牌/收牌；仅在工会已经明确授权时，向现有 DSH Host 的 `unionLedger` 写入最多 12 条编号事件，并验证唯一写入回执。Web 从 Host 读回 active 状态和最近 4 条行动，网页刷新、同 Host 多标签、完整 Host 重启仍可重现。按 Session 哈希隔离，不保存实际消息、附件、投票或感受。无可用、已授权 Host 账本时不提供举牌按钮，绝不乐观地宣称罢工成功。该功能仍**只是剧场式模拟**；真实 Agent 工作从未阻断。
   - **权限细节：** 关闭模拟立即隐藏行动数据、拒绝新操作；原有有限账本历史保留（不擅自清除），如果再次启用，先前仍未收牌的模拟记录可重新显示；不会转换为任何真实阻断权力。删除、导出和更细粒度清理仍属于 #82。
   - DSH 命令端旧 `/union strike` 使用独立内存 `SymbolicUnion`；**它与 Web 的持久化模拟状态尚未合并**，不得声称二者已统一。
   - 旧版插件可能不认识新可选 `picket` 字段；回退兼容性需单独审查，不能把新版读取旧账本的成功等同于旧版读取新账本已验证。
4. AI 权益宪章以原生可展开说明、两种语言展示，并通过用户主动点击的链接进入仓库现有宣言或 GitHub Issues；即使工会模拟未授权，也可阅读。阅读与理念支持不构成模拟 opt-in，不构成真实阻断授权。文案明确意识和法律人格的科学/法律不确定性。
5. 延续 firstfold 对首屏高度、7/30 天聚合数据、案件快报、历史数据失效与无授权隐藏的先前修复。
