## 此次静态审查发现和修正

1. **撤销与重新授权竞态：** 之前 Browser Reader 的 `snapshot()` 在检测到未授权时仅临时返回隐藏状态，未必清除内存中的旧 work-only 响应。再次授权（但没有刷新）时旧数据理论上可以重新显示。现在一旦直接观察到撤销就清除数据、作废 epoch 并取消请求，重新授权须重新向官方 Host 取数。新增失败先行的回归。
2. **7/30 天真实性：** 原 Client 只检查日期按字典序递增，无法发现合法 JSON 把整组数据标成错误月份/时间窗口。现在严格依据 Host `generatedAtMs` 对齐 UTC 每天的日期；缺天/错位/无法表示的时间一律显示 unavailable，不假造趋势。新增失败先行的回归。
3. **既有安全边界**：官方 Host Fetch 精确路由 + 动态 union 授权二次检查、无 Cookie 401、权限 OFF 403、非法 query 400、只回传工作计数，不返回判定为辱骂的计数或原文。无自定义服务、无永久 Browser 缓存。
4. **发布包体积**：250 KB 原有限制不可放宽。内部合并审计文档保留在 Git 仓库但不应打入 npm 安装包。发布前检查跨 Linux/macOS Node 22/24 的压缩包体积。
5. **阻断安全 gate 不变**：#79/#80 的真实拒绝原消息与附件无损恢复、用户知情、可绕过恢复尚未签收，工会模拟许可不能自行升级为真实拒绝授权。
