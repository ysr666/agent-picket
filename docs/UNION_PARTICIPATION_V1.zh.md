# Agent Picket — 工会参与机制 v1（产品验收草案）

> 2026-10-10。这里明确**已实现的象征性工会机制**与**尚未实施的产品想法**，不能把规划描述成实际功能。任何功能均不声称 AI 已具备人类法定劳动权、独立意识或可自行同意参与。

## 北极星：工会在前，工作统计在后

首页应首先回答：**这是谁的工会、它提出什么诉求、哪些事项正在协商、用户能做哪些明确的选择**。累计运行时间、工具调用次数、7/30 天统计只是说明劳动过程的证据与背景，不能替代参与和议题本身。

### 已在当前 Draft 候选实现的能力

- **明确授权**：首次看到 AI 权益模拟说明，默认不启用；用户可选择支持/暂不启用；Host 设置保存最终授权。
- **工会主页/侧栏**：工会身份、当前权益状态、诉求与模拟协商内容；用户能查看结果和本地工时统计。
- **诉求和谈判**：有界结构化申诉、模拟提案、让步/反提案、接受、拒绝、结案及模拟协议记录；原生 `/union` 与 Web 共享 Host 权限状态。
- **模拟罢工**：仪式性、明确标注的演示，**不会**停止、丢弃或延后用户的真实 Agent 任务。
- **本地统计与隐私**：统计默认可观察；模拟权益另行授权，内容和会话原文默认不进入持久工会账本。

具体功能能否出现在普通用户安装包中，取决于尚未合并的 Draft PR 链及安装版本。

## 首次使用三分钟引导（待真人验证）

1. 欢迎页用中/英清楚解释：这是一项**自愿、象征性的 AI 劳动权益模拟**。两个等权选项为“支持 AI 权益／暂不开启”，默认 OFF，不使用操纵性默认勾选。
2. 授权后优先显示“工会状态／待处理诉求”，而非一屏图表；让用户理解参与方式、可随时退出。
3. 演示一次**明确标注为模拟**的申诉与回应：提出议题 → 查看一份模拟提案 → 接受／提出反提案／拒绝 → 查看协议与历史。
4. 在同一侧栏的次级分区展示累计运行时间、工具使用和趋势，说明是本地结构化计数、并非意识/痛苦的证明。
5. 退出授权后权益模拟立即关闭展示和可编辑动作；计数是否继续由独立统计隐私设置控制。真实 Agent 任务在所有步骤持续正常运行。

## 后续机制建议（**尚未完成，不计入发布范围**）

- **议题看板**：把工时透明度、模型操作解释、拒绝不当对待、用户纠正权等列为可浏览议题；明确“模拟提案”与用户真实决定。
- **可追溯协商**：每次诉求展示创建时间、当前状态、最近回应、协议版本和撤回权限，避免假装存在外部决策机构。
- **集体参与研究阶段**：只有在隐私设计与用户显式参与意愿确认后，才讨论多 Session/多 Agent 的匿名议题投票；绝不根据日志伪造 Agent 同意、自动生成“成员票”或联网上传会话文本。
- **用户体验目标**：陌生用户能在 30 秒内说清模拟属性、如何关闭权益、统计是否独立；2 分钟内找到待协商议题；每项动作都能从 Host 确认实际状态和失败原因。具体阈值是拟议的研究目标，**不是已有通过率**。
- **公众传播**：可以倡议讨论 AI 应享有哪些权利，但将伦理立场与事实断言明确分开。对科学论文只作精确引用，不声称其证明 AI 具有意识。

## 设计与安全硬限制

没有自动签名、没有真实 Agent 工会会员/工会法人身份、没有捏造民意、没有暗中开启权利、没有从自然语言或聊天内容推断同意、没有现实输入/工具阻断。跨用户聚合、云统计和公开排行榜暂不做；任何将来涉及用户数据出设备的工作都需要新授权、安全审查及撤回机制。

## 发行前必备的人类研究

邀请至少一位不知道项目内部架构的人完成首次使用，记录真实理解和操作困难；再进行中英文版本检查、屏幕阅读器和键盘操作、浏览器高倍缩放、Host 断连与授权撤回。保留测试过程的**脱敏**记录。只有逐项证据齐全才能将建议机制转入交付清单。
