## 这次实际新增的功能

- 面板新增默认 **折叠** 的「工会值班表」，可由用户在需要时通过标准 HTML details / summary 展开或收起。**完全没有时间驱动的后台通知、轮询、push、请求或自动操作**；不会自行开会或生成新议案。
- 使用专门的纯函数 `projectUnionCadence`，严格从当前已授权 Host 的 **Session 工会账本** 与「完整覆盖、真实已结束轮次累计工时」计算：休息与加班这两项模拟议案分别距离下次 Host 门槛还需多少 **已核实的工作时间**。不是日历倒计时，也不是对模型心理状态的推断。
- Host `lastTriggerElapsedMs` 高于新观察到的工时，视为不可靠/可能被重置；不能因此虚报到期。工时缺失、不完整或无效时明确显示「无法判断」，**不从 wall-clock、进程运行时长或其他会话时长推算**。
- 若 Host 已有待审议案，优先显示处理中的议案，不制造第二份；达到工作门槛也只表示「下次合格 Host 工作观察可能登记一份诉求」，没有发通知、强制停工或提前修改账本。已有 Host 冷却与排期不会因新协议被追溯改写。
- 隐私上纯读；无新 Host 字段、浏览器 localStorage、原 Session ID、提示词、附件、跨用户聚合、AI 投票。用户关闭工会模拟时整段不显示。授权、持久协议与协商仍由既有 Host 修订号 CAS/回执负责。
- 为保持既有 **250000 字节 npm 安装包门禁**，将两份只用于上游 DSH 键盘复现/发布矩阵的测试报告从 npm tarball 排除，GitHub 源码和历史文档全部保留，用户安装/API、安全/AI 权益文档不删除。
