# Windows private ledger NTFS security probe — experimental, NOT storage support

Agent Picket's `DurableStats` deliberately requires UNIX `0o700` directories and `0o600` single-link regular files. Windows `fs.stat().mode` cannot prove private NTFS ownership and DACL security; treating that numeric mode as POSIX would leak private pseudonymous work metadata. The Windows persistent ledger must remain FAIL-CLOSED until a complete owner-only native implementation is independently accepted.

`src/adapters/node/windows-private-acl.ts` introduces **READ-ONLY** `verifyPrivateNtfsAcl` for research, without modifying a user's permissions or writing any data. It rejects unsupported platforms, missing paths, symbolic links, multi-link files, unexpected owners, inherited directory ACLs, ANY allow ACE outside current-user/SYSTEM/built-in Administrators, and missing owner modify rights. An isolated encoded Windows PowerShell/.NET file-security API script reads the actual Windows security descriptor by SID (without Get-Acl/Set-Acl module autoloading), never interpolates a user path as source code, runs without elevation and returns a fixed verdict. Unexpected output, process failure or timeout means `false`. No production adapter currently calls it; installing Agent Picket does not automatically invoke PowerShell or modify an ACL.

`tests/windows-private-acl.test.ts` adds opt-in Windows-native checks: a normal inherited temporary folder is not accepted as private; a disposable folder with an explicit, test-only protected DACL granting only current user, SYSTEM and administrators is accepted; a newly created file inheriting that trusted ACL is accepted; and adding an explicit `Everyone` read ACE makes the verification fail. Test fixtures are synthetic, automatically deleted, and never include user prompts, tokens or sessions. Windows CI uses this suite as portable/core work only; it is NOT a certificate that existing persisted data, lock files and atomic snapshot writes are race-free on NTFS.

Next release-blocking requirements: a race-resistant private Windows directory initialization workflow, reparse-safe parent/open handles, protection of every snapshot and journal/lock file, cross-process mutex and dead-PID recovery, deletion and crash-consistent persistence under actual DACLs, and full unskipped Windows `DurableStats` tests. Do not remove Unix-mode checks on Windows or skip privacy checks to make tests green. No GO for 1.0 until independently verified.
