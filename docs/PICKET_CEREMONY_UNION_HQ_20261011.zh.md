# Agent Picket · 纠察现场与双阶段行动仪式（#74 / #75）

> 2026-10-11，独立 Draft 增量。基于 #108 的确切 Git tree，**模拟工会行动**，不阻断真实 Agent 工作，不代表独立 AI 投票或确证的受害经历。

## 为什么做

已有 Host 纠察牌能够记账并跨标签页/重启恢复，但首屏仍以「举牌/收牌」按钮和技术性回执呈现。新设计在 Union HQ 的首要行动区域增加一面**由真实 Host 已保存状态控制**的实体感纠察牌，配合醒目的工会标语、当前状态、最近事件编号和明确的仪式性操作。

## 用户可见机制

- **场景**：深绿布告栏和赭色影框的象征性纠察牌，英文/简体中文文字由现有 i18n 提供。窄屏自适应双列/单列布局；舞台纯 CSS，无动画、额外素材或网络请求。海报视觉隐藏于读屏器，独立的文字状态可被播报。
- **登记依据**：状态和行动历史由真实 Host 读回；没有从 React 临时选择生成虚假的投票、会议记录、人数或工作统计。说明两个不同账本中的诉求与举牌**不自动具有因果关系**。
- **用户操作**：点击「举牌」或「收牌」先打开有明确安全说明的确认仪式。此时**没有 Host 写入**；取消完全无副作用。二次点击确认才使用既有 Host API；仍依靠底层 CAS、当前 Session 和随机回执校验。成功后读取 Host 最新快照，才能呈现已登记状态。
- **过期操作**：保存确认时的 Session 范围、最后事件号和拟执行的方向。会话、授权或 Host 纠察状态变化后，确认界面作废；不存在跨 Session 沿用已确认操作。
- **隐私与兼容**：没有新增持久化字段、不储存原文/附件/Session ID、不改变三个现有 v1 账本或 DSH 对话文件。拒写会保留错误提示，不展示本地虚假成功。
- **权力边界**：用户主动启动的是有记录、有状态、可撤回的象征性行动。真实任务拦截继续 OFF，#80 全原始消息和所有附件无损恢复门禁没有改变。
