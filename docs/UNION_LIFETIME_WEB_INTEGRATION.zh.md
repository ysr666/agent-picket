## 安全
- Browser 仅通过官方 DSH Connection Fetch 接口同源认证读取工作聚合；无新本地存储、未采集原始消息或工具参数。
- 权限关闭立即隐藏历史，取消在途请求；Session 切换和 Host 重连使用版本戳拒绝旧结果复活。Host 端每次请求二次检查当前授权、响应不缓存。
- Browser 严格白名单解析，不允许额外键，不接受辱骂分类、会话标识或原始文本。
- DSH 0.1.2 不能按 0.2 的通道读取数据时正常降级，不阻断 Agent 任务。
