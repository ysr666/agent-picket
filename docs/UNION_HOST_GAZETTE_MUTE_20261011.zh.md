# Agent Picket · Host 持久小报静音偏好（2026-10-11）

> 基于 Draft #97 的独立增量。真实 Agent 任务阻断、后台通知、自动推送与自动工会会议仍然 OFF。本文件仅为审查证据，不随 npm 用户包分发。

## 语义与兼容边界

- 新增官方 Host `agent-picket` 命名空间中的 **`unionGazetteMode: 'visible'|'quiet'`**，默认 `visible`。这只是「工会小报」故事正文的显示偏好，**不是启用后台提醒的授权，也不影响现有协商、纠察、工作数据、工会参与与任务运行**。
- 当前用户只有在**明确开启工会模拟**，并持有可写的真实官方 Host Settings 时，才可保存这个偏好。关闭模拟会立即隐藏小报，Host 仍保留已有可恢复的选择；重新开启时依据该偏好决定是否显示正文。退出模拟不删除工会账本或变成永久退会。
- 新字段与 `unionLedger`、`unionPicketLedger` 分离，不修改严格历史账本 Schema。旧值缺少新字段时默认可见；字段非法时新版 Host/Client 应拒绝或失效关闭。**新插件写入字段后，回退到历史老插件版本读取新设置的全版本矩阵尚未验收**，必须在 #91 继续 HOLD。
- DSH 0.2 新桥使用官方 `remote.settings.mutate` 修订号 CAS，验证实际字段回执和整个 Host 设置视图；DSH 0.1 通过官方 `settingsScope` 及 Host Schema 读写。前端另行检查读回的模式与请求值完全相同，静默丢写和 Host 拒绝绝不视为成功。
- 偏好是跨 Session 的一个全局工会界面选择，跨两个真实 Chrome 标签、浏览器刷新和完整 Host 重启生效。它不是每个 Agent 的个人身份认证或投票；**无新浏览器本地存储、原提示词、附件、原始 Session ID、云端追踪，也不保留 AI 情绪**。
- 本轮保留默认值为 `visible`，仅模拟开启后显示；但静音不会遗漏真实 Host 案件，它只是暂时不显示小报故事正文，恢复后仍以 Host 最新账本生成，不回放伪造旧时间戳。
